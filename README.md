## Cel projektu
Celem niniejszego opracowania jest analiza statystyczna czynników wpływających na wydatek energetyczny oraz profil metaboliczny populacji liczącej niemal 20 000 rekordów. Badamy relacje między typem treningu (HIIT, Cardio, Joga), dietą a parametrami takimi jak BMI czy tętno.

## Najważniejsze wnioski
* Trening **HIIT** wykazuje najwyższą efektywność metaboliczną.
* Regularność treningów jest kluczowym predyktorem spalania kalorii.
* Płeć i wiek nie różnicują istotnie preferencji treningowych ani tętna wysiłkowego.
